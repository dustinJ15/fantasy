# Failure modes that are fixed

For an agent working an item, or anyone who sees an old symptom come back. Each row is a failure Dustin could see
in an email, its cause, and the fix with its date and TODO id, grouped by area. CLAUDE.md keeps only the rows that
are still open or are checks to run; a fix that closes a visible failure adds its row there, and when a later
session trims CLAUDE.md the rows that read "fixed <date>" move here. Function and constant names, never line
numbers; the dates say which checkout to read.
